# fonts/

Fonts from the maintainer's library whose own license allows redistribution (SIL Open Font
License 1.1, Apache License 2.0 and similar). The license text is embedded in each font file
(name table) — open the font's "详情" panel in the app to read it. Reserved Font Names in OFL
fonts must not be used for modified versions.

可再分发的开源字体（OFL / Apache 等），授权文本内嵌在每个字体文件里，可在程序“详情”中查看。
