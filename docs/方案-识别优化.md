# 截图识字优化方案（v3）

> 2026-10-30 建立。起因：真实截图测试中，正确字体（Caysley → Pacifico）只排第 3 名、39 分；在线检索（dafont 分类热门前 200）基本命中不了。

## 调研结论（2026-10-30）
- 本地低分的根因是抠图：花背景大片混入文字掩码。按颜色聚类抠图后，Pacifico 排到第 1 名、99 分（原为第 3 名、39 分）。
- 现在显示的“分”是原始相似度 ×100，不是百分比。本地库没有该字体时，最高分约 20–30。
- Vision 前景抠图（VNGenerateForegroundInstanceMaskRequest）对文字图片无效，已实测排除。
- dafont 约 10 万款字体，“分类热门 200”覆盖率太低，属于结构性问题。
- 可程序化调用的识别服务只有 WhatFontIs API（每天 200 次免费，覆盖约 100 万款字体，含免费字体）；WhatTheFont、Matcherator、Adobe、Lens 都没有官方 API。
- 让大模型直接说出字体名的准确率低（Top-1 只有 5–31%），不采用。
- Google Fonts 中拉丁 Display + 手写类约 720 个家族，许可为 OFL/Apache，可商用。

## 阶段与范围（用户 2026-10-30 确认：A→B→C 逐阶段验收）
### 阶段 A：本地准确度（不联网）
1. 抠图同时用两条路：原方法 + 颜色聚类，取比对分更高的一路；描边/泡泡字额外生成“填实”版本参与比对。
2. 装饰花纹行不参与比对：行数多于单词数时，只保留墨量最大的几行。
3. 分数分三档（很像/可能/不像）；最高分偏低时提示“本地可能没有，建议在线检索”。阈值按命中率实验的分数分布确定。
4. 命中率实验加入“花背景”“描边贴纸”两种样本；同时用 data/history 里的真实截图做回归测试。
### 阶段 B：Google Fonts 入库
- 只下载拉丁 Display + Handwriting 两类（用户确认）；标签“Google 可商用”；字形图集控制内存占用。
### 阶段 C：在线检索重做
- 先用免费额度拿 10 张真实截图试跑 WhatFontIs，效果达标再接入（用户已同意截图外发）。
- 接入后：取 WhatFontIs 前 20 名候选，用本地比对算法重新排序，并显示授权信息；dafont 分类浏览只保留为手动入口。

## 变更记录
- 2026-10-30：建立 v3 方案（替代原计划“阶段 4 在线兜底”的 dafont 分类抓取思路）。
- 2026-10-30：阶段 A 实施调整。颜色抠图不再整簇合并相近颜色，改为按像素到文字颜色的距离判断（阈值取 25 和到相邻颜色簇距离一半中的较小者），原因是整簇合并会把相近颜色的背景块一起抠进来。分档阈值按实验分布确定为 88/55，“很像”档从初定的 85 上调到 88，因为本地没有该字体时最高分的 90 分位是 86。已知限制：带渐变描边的泡泡字（如 ANSLEY）仍抠不出实心字形，这类结果会被标为“不像”。
- 2026-10-30：阶段 B 完成。实际入库 716 个家族：有 6 个 Edu 系列手写体在仓库里找不到对应目录，已跳过。可变字体只渲染默认字重。顺带修复了 Atlas.build 读取 npz 时反复解压整个数组的 bug，这是此前进程内存暴涨、实验进程被系统杀掉的原因。字体库从 568 个字形扩到 1337 个后，单次检索变为 1–4 秒；对照实验显示，原有字体的命中率下降 0–4 个百分点（手写体描边贴纸样本少，降了 11 个百分点）。
- 2026-10-30：阶段 C 方案变更（用户确认）。用户不希望注册 WhatFontIs API，担心实用性。核实发现 img.dafont.com 的 robots.txt 为 `Disallow: /`，原来的 dafont 自动抓取不合规，因此改为：服务端生成干净的黑白字形图（已去掉装饰和半截行），前端一键复制图片并打开识别网站，美工手动粘贴；dafont 只保留在用户自己浏览器里打开分类页的链接。另外新增 OCR 兜底：原图识别不出文字时，改用干净字形图再识别（Caysley 这张实测有效）。WhatFontIs API 作为以后可选的增强，不冲突。
- 2026-11-02：公开发布（用户确认）。系统字体、商业字体和仅限个人使用的字体不能再分发，不上传字体文件，只上传 refs/ 识别数据（每个字体 76 个字符、96px 的字形位图，加字距和元数据）。在全新克隆里验证：AUBREY 仍识别为 Academic M54（93 分）；50 个此类字体的合成样本前 10 命中 84%，使用真实字体文件时为 86%。data/（客户截图、本机路径）不上传。
